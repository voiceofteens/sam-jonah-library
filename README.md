# Sam Jonah Library Booking
1. Start Apache + MySQL in XAMPP and place this folder in htdocs.
2. Import database/schema.sql in phpMyAdmin (schema was inferred from the code - compare with your existing DB first).
3. Create the first admin from the XAMPP shell: php database/create-admin.php "Your Name" you@example.com YourPassword
4. Open http://localhost/sam-jonah-library/
